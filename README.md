# Mani Yarasingu — Recruiter Portfolio

A fast, responsive, free-to-host portfolio built with plain HTML, CSS and JavaScript.

## 1. Open in VS Code

1. Extract this folder.
2. Open the folder in VS Code.
3. Open `index.html`.
4. Install the **Live Server** extension if you want a local preview.
5. Right-click `index.html` → **Open with Live Server**.

You can also double-click `index.html` and open it directly in a browser.

## 2. Add your resume

Create this folder:

`assets`

Put your PDF resume inside it with this exact name:

`Mani_Yarasingu_Resume.pdf`

The Resume button will then work.

## 3. Update your GitHub project links

The project buttons currently point to your GitHub profile. Replace each URL in `index.html` with the specific repository URL when you have the repos ready.

## 4. Free deployment — GitHub Pages

### Create repository

Create a new GitHub repository named:

`mani-yarasingu-portfolio`

Upload these files:

- `index.html`
- `style.css`
- `script.js`
- `README.md`
- `assets/Mani_Yarasingu_Resume.pdf`

Then go to:

**Repository → Settings → Pages**

Choose:

- Source: **Deploy from a branch**
- Branch: **main**
- Folder: **/ (root)**

Save it. GitHub will give you a public URL.

## 5. Optional custom domain

You can later connect a domain such as:

`maniyarasingu.in`

without changing the portfolio code.

## Important recruiter checklist

Before sending the portfolio:

- Add direct URLs for each GitHub project.
- Upload the latest ATS resume.
- Make sure LinkedIn URL is correct.
- Test the Email button.
- Test the site on mobile.
- Check that every project description is accurate.
- Do not claim production experience you do not have.
